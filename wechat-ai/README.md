# wechat-ai — Achi 微信 AI 陪聊机器人

基于 OpenClaw 的便携运行环境。本目录包含启动脚本与使用说明。

- 使用说明.md — 完整使用说明
- 语音通话与声线方案.md — 本地语音方案
- 进展日志.md — 开发日志
- start.cmd — 启动 Achi 网关
- oc.cmd / oc.ps1 — OpenClaw 命令行入口
- setup-*.cmd — 各类密钥与登录配置脚本

> 注意：运行时目录（home、localappdata、cache、logs、temp、runtime、npm-global、node_modules 等）包含微信登录会话与本地凭据，未纳入本仓库。
>
